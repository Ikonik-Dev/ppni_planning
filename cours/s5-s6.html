🔌 Séquence 5.3 — Comprendre les APIs REST

Durée : 2h — JSON + 5 méthodes HTTP + codes statut + tests live

💡 Idée clé : Une API REST, c'est comme un menu de restaurant. Tu envoies une commande (requête HTTP) au serveur (API), il te répond avec des données (JSON). La méthode (GET/POST/PUT/DELETE) dit ce que tu veux faire, et le code de réponse (200/404/500) dit si ça a marché.
10% — Théorie

JSON & méthodes HTTP

  • JSON : texte structuré {"clé": "valeur"}
  • GET — lire des données (sans modifier)
  • POST — créer une nouvelle ressource
  • PUT — remplacer une ressource entière
  • PATCH — modifier partiellement
  • DELETE — supprimer une ressource
  • Codes : 200 OK · 201 Created · 400 Bad Request · 401 Unauthorized · 404 Not Found · 500 Server Error
⏱ 30 min
70% — Pratique

Explorer JSONPlaceholder en live

  • Navigateur : GET https://jsonplaceholder.typicode.com/posts
  • Lire et comprendre la structure JSON retournée
  • GET /posts/1 — un seul article
  • GET /users/1/posts — posts d'un utilisateur
  • DevTools → onglet Réseau → observer headers + body
  • Identifier : Content-Type, Status Code, Response Time
⏱ 75 min
20% — Collaboration

🤖 Séquence 5.6 — Premier workflow N8N

Durée : 2h — Compte cloud + Hello World + HTTP Request

🤖 N8N, c'est quoi ? N8N est un outil d'automatisation no-code/low-code. Tu connectes des "nœuds" (blocs) qui s'enchaînent : un déclencheur (Trigger) → des actions → un résultat. Comme des dominos, mais pour automatiser des tâches répétitives.
10% — Théorie

Concepts N8N essentiels

  • Workflow : enchaînement de nœuds
  • Nœud (Node) : un bloc qui fait une action
  • Trigger : nœud de départ (Manuel, Schedule, Webhook)
  • Connexion : flèche entre deux nœuds
  • Exécution : run du workflow en entier
⏱ 20 min
70% — Pratique

Hello World N8N

  • Créer un compte sur app.n8n.cloud
  • Créer un nouveau workflow vide
  • Ajouter un nœud Manual Trigger
  • Ajouter un nœud HTTP Request → GET JSONPlaceholder /posts/1
  • Connecter les deux nœuds → cliquer "Execute"
  • Observer les données JSON dans le panneau de résultat
  • Sauvegarder et nommer le workflow "Hello World"
⏱ 75 min
20% — Collaboration

Qu'est-ce qu'un Webhook ?

🚀 Séquence 6.3 — Projet libre au choix

Durée : 2h40 — Travail en binôme, 5 options de projet

🎯 À vous de jouer ! Chaque binôme choisit un projet parmi les 5 options ci-dessous. L'objectif : avoir un workflow fonctionnel de 3 nœuds minimum, exportable en JSON, avec un README qui explique ce qu'il fait.
Les 5 projets au choix

Options de projet

  • Option 1 — Météo automatique : récupérer la météo via Open-Meteo API + formater un rapport
  • Option 2 — Agrégateur d'actualités : RSS feed → filtrer → afficher les 5 dernières
  • Option 3 — Webhook formulaire : recevoir des soumissions + envoyer confirmation
  • Option 4 — Moniteur d'API : appeler une API toutes les X minutes + IF erreur → alerte
  • Option 5 — Data transformer : prendre du JSON complexe + reformater en CSV ou structure simple
⏱ 10 min choix
70% — Pratique

Construction du projet

  • Planifier le workflow sur papier (nœuds + connexions)
  • Implémenter dans N8N nœud par nœud
  • Tester chaque nœud individuellement
  • Exécuter le workflow complet
  • Exporter en JSON (menu → Download)
  • Pousser le JSON sur GitHub dans le dossier workflows/
