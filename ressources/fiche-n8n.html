🧠 Concepts fondamentaux N8N

N8N est un outil d'automatisation de workflows. Tu connectes des nœuds (blocs) qui s'enchaînent : un déclencheur reçoit un événement, des nœuds de traitement transforment les données, et un nœud final envoie le résultat quelque part.

Schéma d'un workflow typique

🔔 Trigger Déclenche l'exécution
→
🔌 HTTP Request Appelle une API
→
🔀 IF / Set Filtre / Transforme
→
✅ Action finale Email, Webhook, DB…
ConceptDéfinitionAnalogie
Workflow Enchaînement de nœuds connectés qui réalisent une automatisation Une recette de cuisine avec des étapes
Trigger Nœud de départ qui déclenche l'exécution (manuel, planifié, webhook…) Un réveil qui démarre ta journée
Node Un bloc fonctionnel qui réalise une action (requête, transformation, condition…) Une machine-outil dans une usine
Connexion La flèche qui relie deux nœuds et transmet les données du premier au second Un tapis roulant entre les machines
Exécution Une instance d'un workflow qui s'est lancée — succès, erreur ou en cours Une production en usine (un run)
Item Un enregistrement de données qui traverse le workflow (objet JSON) Un colis sur le tapis roulant

🔧 Nœuds essentiels

Triggers — Déclencheurs

NœudRôleQuand l'utiliser
Manual Trigger Lance le workflow manuellement en cliquant "Execute" Tests, démos, workflows à lancer à la demande
Schedule Trigger Lance selon une planification cron (toutes les heures, chaque lundi…) Rapports automatiques, monitoring régulier
Webhook Génère une URL qui écoute les requêtes HTTP entrantes Formulaires web, GitHub events, Stripe paiements

Core — Nœuds de traitement

NœudRôleExemple d'usage
HTTP Request Envoie une requête HTTP (GET, POST, PUT, DELETE…) vers n'importe quelle API Récupérer des données JSONPlaceholder, appeler Open-Meteo
IF Branche le workflow selon une condition (true/false) Si userId == 1 → aller à droite, sinon → aller à gauche
Set Crée/renomme/transforme des champs dans les données Renommer "body" en "description", calculer une valeur
Code Exécuter du JavaScript personnalisé sur les données Transformations complexes non couvertes par Set
Switch Branche sur plusieurs sorties selon une valeur Router selon le type d'événement reçu
Merge Fusionne les sorties de plusieurs branches Rejoindre deux chemins IF après traitement

Actions — Sorties

NœudRôle
Respond to Webhook Envoie une réponse HTTP au client qui a appelé le webhook
Send Email Envoie un e-mail via Gmail, SMTP ou autres
Write Binary File Écrit des données dans un fichier (CSV, JSON, texte)

✍️ Expressions N8N — accéder aux données

Les expressions N8N utilisent la syntaxe {{ expression }}. Elles permettent de référencer les données des nœuds précédents, créer des valeurs dynamiques, et effectuer des transformations à la volée.
// Accéder aux données du nœud précédent ($json) {{ $json.title }} → champ "title" du dernier nœud {{ $json.user.email }} → champ imbriqué (objet dans objet) {{ $json.tags[0] }} → premier élément d'un tableau // Accéder aux données d'un nœud précis par nom {{ $('HTTP Request').item.json.id }} → id du nœud "HTTP Request" // Variables spéciales {{ $now }} → date/heure actuelle (objet DateTime) {{ $now.toISO() }} → format ISO 8601 : "2026-06-15T09:00:00.000Z" {{ $runIndex }} → index de l'item courant (commence à 0) {{ $itemIndex }} → position dans la liste d'items // Manipulation de chaînes {{ $json.name.toUpperCase() }} → ALICE {{ "Bonjour " + $json.prenom }} → concaténation {{ $json.email.split("@")[1] }} → domaine de l'email // Conditions ternaires {{ $json.score >= 14 ? "Validé" : "À revoir" }}
VariableCe qu'elle contient
$json Données JSON de l'item courant (dernier nœud)
$('NomDuNœud').item.json Données d'un nœud précédent identifié par son nom
$now DateTime actuel (méthodes : .toISO(), .toFormat('yyyy-MM-dd')…)
$env.NOM_VAR Variable d'environnement N8N configurée dans les paramètres
$runIndex Index d'exécution (0 pour le premier item traité)

📤 Export & Import de workflows

Exporter un workflow (JSON)

ÉtapeAction
1 Ouvrir le workflow dans N8N
2 Cliquer sur les 3 points (⋮) en haut à droite → Download
3 Sauvegarder le fichier My_workflow.json
4 Committer le fichier JSON dans workflows/ sur GitHub

Importer un workflow

ÉtapeAction
1 Sur la page d'accueil N8N → cliquer Add workflow
2 Cliquer sur les 3 points (⋮) → Import from file
3 Sélectionner le fichier JSON
4 Vérifier les credentials (tokens, clés API) — ils ne sont pas exportés !
Important : Les credentials (mots de passe, tokens API) ne sont jamais inclus dans l'export JSON pour des raisons de sécurité. Après import sur une nouvelle instance, reconfigurer tous les nœuds qui utilisent une authentification.

🔒 Bonnes pratiques sécurité N8N

PratiquePourquoiComment
Credentials — jamais en dur Les tokens dans le workflow JSON seraient visibles à tous Utiliser le gestionnaire de credentials N8N (section Credentials)
Variables d'env Séparer la configuration du code Settings → Variables → définir KEY=VALUE → accéder via $env.KEY
Webhook secret N'importe qui avec l'URL peut déclencher le webhook Activer "Webhook Auth" dans les paramètres du nœud Webhook
Validation d'entrée Un webhook malveillant peut envoyer des données inattendues Toujours valider les données reçues avec un nœud IF ou Code
Logs d'exécution Les logs peuvent exposer des données sensibles Éviter de logger des tokens ou PII dans les nœuds Set/Code
HTTPS uniquement Les webhooks HTTP peuvent être interceptés Toujours utiliser des URLs HTTPS pour les webhooks
// Exemple : nœud IF pour valider une donnée de webhook entrante Condition : {{ $json.secret }} === "ma_valeur_secrete" → True : continuer le traitement → False : ignorer / retourner 403
