Mon compte GitHub
9h00 → 9h30
🐙 C'est quoi GitHub ? GitHub, c'est un site web. Il sert à stocker des projets informatiques.
Ton projet sera visible par tout le monde. C'est une vitrine professionnelle.
Beaucoup d'employeurs regardent GitHub avant un entretien d'embauche.
C'est comme un portfolio en ligne — mais pour tes projets numériques.

Deux situations → lis la tienne :

🆕 Je n'ai pas encore de compte
  • 1. Va sur github.com Ouvre un nouvel onglet. Tape l'adresse dans la barre.
  • 2. Clique sur "Sign up" "Sign up" = "S'inscrire". C'est le bouton en haut à droite.
  • 3. Entre ton adresse e-mail Utilise une adresse que tu consultes vraiment.
  • 4. Choisis un nom d'utilisateur professionnel Exemples : prenom-nom ou prenomN.
    Pas de surnom de jeu vidéo — c'est ta carte de visite.
  • 5. Confirme ton e-mail GitHub t'envoie un code par e-mail. Ouvre ta boîte mail. Tape le code.
📖 Fiche Git → Créer son compte
✅ J'ai déjà un compte
  • 1. Va sur github.com Ouvre un nouvel onglet. Tape l'adresse.
  • 2. Clique sur "Sign in" "Sign in" = "Se connecter". Entre ton nom d'utilisateur et ton mot de passe.
  • 3. Vérifie que tu es connecté·e Ton avatar doit apparaître en haut à droite de la page.

Créer mon repository
9h30 → 11h00
📁 C'est quoi un repository ? Un repository (on dit "re-po"), c'est un dossier en ligne.
C'est là où GitHub range ton projet.
Tout le monde peut voir ton dossier. C'est fait pour ça.
C'est comme un classeur partagé — mais sur Internet.
👥 En binôme :
Une personne suit les étapes sur son ordinateur.
L'autre observe via Discord et dit si elle voit la même chose.
Ensuite vous inversez les rôles pour l'étape suivante.
  • 1. Clique sur le "+" en haut à droite Tu le vois sur toutes les pages GitHub une fois connecté·e.
  • 2. Clique sur "New repository" "New repository" = "Nouveau dossier de projet".
  • 3. Dans "Repository name", tape exactement : mon-premier-repo (tout en minuscules, pas d'espaces, tirets seulement)
  • 4. Dans "Description", écris une phrase courte Exemple : Mon premier projet GitHub — PPNI 2026
  • 5. Sélectionne "Public" Ton projet sera visible en ligne. C'est ta vitrine professionnelle.
  • 6. Coche "Add a README file" Ça crée automatiquement ton fichier de présentation. On va le modifier juste après.
  • 7. Clique sur "Create repository" Ton projet est créé ! Tu dois voir une page avec un fichier README.md dedans.

Écrire mon README
11h00 → 12h00
📄 C'est quoi un README ? Un README, c'est la page d'accueil de ton projet.
C'est la première chose que les gens voient quand ils ouvrent ton repo.
C'est ta présentation. Tu parles de toi et de ce que tu fais.
C'est la couverture d'un livre — mais pour ton projet GitHub.
✍️ C'est quoi le Markdown ? Le Markdown, c'est une façon d'écrire du texte mis en forme.
Tu utilises des petits symboles. Le site les transforme en joli texte.

Tu écris # Bonjour → ça devient un gros titre
Tu écris ## Titre 2 → ça devient un sous-titre
Tu écris **mot** → ça devient du texte en gras
Tu écris - élément → ça devient une liste à puces

🧩 Modèle à copier dans ton README :

# ← Ce symbole crée un gros titre # 👋 Bonjour, je suis [ton prénom] ! ## ← Sous-titre ## Qui suis-je ? Je m'appelle [ton prénom]. Je suis stagiaire dans le programme PPNI 2026. J'apprends le numérique avec Auxilia Formation. ## Ce que j'apprends cette semaine - ← Crée une liste à puces - La cybersécurité - Comment créer un compte GitHub - Comment écrire un README ## Une chose que j'aime [Écris une chose que tu aimes — un loisir, une passion, n'importe quoi !] ## Mon profil GitHub Retrouve-moi ici : [ton lien github.com/ton-prenom]
📝 Fiche Markdown → Tous les symboles expliqués

Étapes pour écrire :

  • 1. Ouvre ton repository sur GitHub Tu vois un fichier README.md sur la page d'accueil du repo.
  • 2. Clique sur le crayon ✏️ Il est en haut à droite du fichier README. Il ouvre l'éditeur de texte.
  • 3. Sélectionne tout et efface Clique dans le texte → Ctrl + A pour tout sélectionner → Suppr pour effacer.
  • 4. Copie-colle le modèle ci-dessus Remplace ensuite chaque [...] par tes vraies informations.
  • 5. Clique sur "Preview" pour voir le résultat Tu vois comment ça s'affichera vraiment. Si quelque chose semble bizarre, reviens en mode édition.

▶ Reprise — 13h30

Suite de l'étape 2 — Finalise et sauvegarde ton README :

  • 6. Relis ton README depuis le début Corrige les fautes. Vérifie que les informations sont exactes. C'est un document public.
  • 7. Ajoute une chose personnelle si tu veux Un emoji, une citation, une photo — c'est ton projet, exprime-toi.
  • 8. Clique sur "Commit changes…" C'est le bouton vert en haut à droite de l'éditeur. "Commit" = sauvegarder officiellement.
  • 9. Écris un message de commit Dans le champ "Commit message", écris : Rédiger mon README de présentation
  • 10. Clique sur "Commit changes" (le bouton de confirmation) Ton README est sauvegardé et visible en ligne. Ton premier commit est fait !
📸 C'est quoi un commit ? Un commit, c'est une sauvegarde officielle de ton travail.
GitHub garde l'historique de toutes tes sauvegardes.
Tu peux toujours revenir à une version précédente.
C'est comme une sauvegarde de jeu vidéo — avec une description.
